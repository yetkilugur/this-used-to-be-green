blank. But scroll back through the years and you'll find a small confession
hidden in the contribution graph:

> **2023:** SO EMPTY → **2021:** BUT ONCE → **2020:** IT WAS ALL → **2019:** GREEN HERE → **2017:** I SWEAR

*"So empty… but once it was all green here… I swear."*

project I'd worked on, my commit history walked out the door with me — and what
was left behind turned into this empty calendar.

My code is still running somewhere out there. It just doesn't have my name on
it anymore. 🌱 → 🫥
